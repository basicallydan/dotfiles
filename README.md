# Dotfiles (macOS Catalina)

**Welcome to my dotfiles!**

This repository is a collection of config files I use to setup my MacOS Catalina machine. It uses Homebrew/Casks to manage most of my applications, ZSH as the shell and VIM as the terminal editor.

It also contains a few "me" specific configuration files e.g. `./git/gitconfig` so if you're interested in using my dotfiles, you may want to leave those out!

I built this from scratch but loosely based it on https://github.com/davidvuong/dotfiles/

## Download & Install

1. Clone the repository:

   ```bash
   git clone git@github.com:basicallydan/dotfiles.git ~/dotfiles && cd ~/dotfiles
   ```

1. Run the installation script:

   ```bash
   bash ./scripts/install.sh
   ```
